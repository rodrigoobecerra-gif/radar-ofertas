# Radar de ofertas — piloto privado

Prueba búsquedas activas de ebooks y apps en Meta Ads Library. Las búsquedas planificadas en `searches.json` se centran en salud, dinero y amor para Argentina y Brasil. Abre resultados y resúmenes de anuncios, registra solamente IDs individuales activos con destino web visible y agrupa por anunciante y URL exacta. Si un grupo tiene más de 20 IDs, abre la página y exige título, precio y acción de compra observables.

El flujo semanal recorre 12 búsquedas y deja el informe privado en `reports/latest.md`, además de un artefacto de GitHub Actions. En una solicitud de cambios recorre solo dos búsquedas para validar el funcionamiento. El resumen de Meta se usa para elegir qué revisar, nunca como recuento de una oferta. Luego abre hasta tres bibliotecas de anunciantes por búsqueda y cuenta únicamente IDs individuales con destino observado **dentro de esa biblioteca**. Si la biblioteca del anunciante no carga, el grupo no califica aunque tenga IDs en la búsqueda inicial. El informe declara esta cobertura acotada y registra los enlaces de las bibliotecas efectivamente revisadas.

No se infieren ventas, gasto, rentabilidad ni visitas a la URL: Meta no publica esas visitas y una estimación del dominio no equivale al tráfico de la página. Más de 20 IDs demuestra actividad publicitaria observable, no validación financiera. Una página tipo cuestionario o descarga de app no califica. Cada oferta exige al menos 21 IDs individuales activos con el mismo anunciante y URL exacta, y una página con precio, acción de compra y señales del producto ebook/app. Una falla total de extracción no reemplaza el último informe privado. **Este flujo no actualiza el Site privado.**
